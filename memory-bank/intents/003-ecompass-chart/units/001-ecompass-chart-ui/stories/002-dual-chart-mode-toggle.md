# Story: Dual Chart Mode Switcher

## User Story
As a visitor,
I want to toggle between the live eCompass DEX chart and the simplified SVG price curve,
So that I can choose between an in-depth trading view and a quick lightweight trajectory overview.

## Acceptance Criteria
- [ ] Toggle buttons placed in the chart header: **eCompass DEX Chart 📊** and **Overview 📈**.
- [ ] Active toggle button highlighted with neon cyan pill styling.
- [ ] Toggling between modes switches view visibility smoothly without page reloads.
- [ ] Preserves SVG interactive timeframe controls when in Overview mode.
