# Story: External Action Controls to eCompass

## User Story
As a visitor,
I want a direct button linking to the eCompass token portal,
So that I can open eCompass in a full separate tab to use advanced charting tools, order book depth, or share chart snapshots.

## Acceptance Criteria
- [ ] Direct action button: "Open in eCompass ↗" leading to `https://e-compass.io/tokens/ECAT-4ebd0f`.
- [ ] Formatted with external link attributes (`target="_blank" rel="noopener noreferrer"`).
- [ ] Styled with subtle glowing border and hover micro-interaction.
